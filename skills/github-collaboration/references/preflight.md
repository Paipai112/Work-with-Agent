Inspect current Issue/PR/claim lineage and local Git state for the next operation. First Issue/claim/discussion/review needs no prior implementation claim; implementation/file/branch/stage/commit/push needs current uncontested scope. Use this package's operation references; missing procedures block dependent writes. Daily never initializes Git/repositories.

Record `read-only`, `member` or `leader:<ceiling>`, exact task/delegated scope and next allowed operation. Report missing evidence without granting authority. Local edits refresh diff/index/ownership; unchanged trusted package records need no redownload.
